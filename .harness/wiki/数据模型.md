# 数据模型

> 🔧 模板说明：「MyBatis-Plus 约定」与「Redis Key 约定」为通用约定可直接沿用；表清单与 Key 前缀按项目填充。

## {module} 模块数据表（示例：order 模块）

> 每模块一节：表数量 + 全量表清单（表名/PO 类/说明/关键字段）。

| 表名 | PO 类 | 说明 | 关键字段 |
|------|-------|------|---------|
| t_order（示例） | OrderPO | 订单表 | order_id, user_id, status, amount |

## MyBatis-Plus 约定

| 约定 | 说明 |
|------|------|
| PO 命名 | `{Entity}PO`，标注 `@TableName("t_xxx")` |
| Mapper 命名 | `{Entity}Mapper extends BaseMapper<{Entity}PO>` |
| 主键 | `@TableId(type = IdType.AUTO)` 自增主键 |
| 逻辑删除 | `@TableLogic` del_flag 字段 |
| 自动填充 | `@TableField(fill = FieldFill.INSERT)` create_time |
| 字段映射 | 驼峰 ↔ 下划线自动映射（MyBatis-Plus 默认） |

## Redis Key 约定

> 统一前缀 `{app}:`（替换为项目简称），按用途分段。

| Key 模式 | 说明 | TTL |
|---------|------|-----|
| `{app}:token:{userId}`（示例） | 登录 Token | 30min |
| `{app}:idempotency:{key}`（示例） | 幂等校验 | 24h |
| `{app}:lock:{resource}`（示例） | 分布式锁 | 30s |
