# 领域术语

> 🔧 模板说明：「架构术语」「代码层术语」「异常术语」「HTTP 状态码约定」为通用内容可直接沿用；
> 「业务术语」必须按项目填充——需求分析（doc-analysis R6/§13）与编码的新造词判定均以本表为准。

## 架构术语

| 术语 | 英文 | 说明 |
|------|------|------|
| COLA | Clean Object-oriented and Layered Architecture | 阿里开源的 DDD 架构风格 |
| 防腐层 | ACL (Anti-Corruption Layer) | 隔离外部服务的接口层 |
| 领域规约 | Policy/Spec | 纯函数校验规则 |
| 领域装配 | DomainConfig | domain 层与 Spring 的唯一接触点 |
| 应用服务 | AppService | 技术编排层，不含业务规则 |
| 聚合根 | Aggregate Root | DDD 中一致性边界内的根实体 |
| 值对象 | Value Object | 不可变的领域概念，用 record 表示 |
| 命令 | Command | 应用层参数对象，JDK 21 record |
| 转换器 | Assembler | DTO↔Command↔Domain 双向转换 |

## 代码层术语

| 术语 | 位置 | 说明 |
|------|------|------|
| interfaces | {module}/interfaces/ | 接口层（Controller/DTO/Assembler） |
| application | {module}/application/ | 应用层（AppService/Command/DomainConfig） |
| domain | {module}/domain/ | 领域层（Model/Service/Repository/ACL/Policy） |
| infrastructure | {module}/infrastructure/ | 基础设施层（Persistence/ACLImpl/GatewayImpl） |
| PO | infrastructure/persistence/po/ | 持久化对象，MyBatis-Plus 表映射 |
| Mapper | infrastructure/persistence/mapper/ | MyBatis-Plus BaseMapper 接口 |

## 异常术语

| 术语 | 说明 |
|------|------|
| DomainException | 领域异常（code + message） |
| GlobalExceptionHandler | 接口层统一异常处理 |
| ErrorCode | 错误码枚举 |

## HTTP 状态码约定

| Code | 含义 |
|------|------|
| 200 | 成功 |
| 400 | 业务异常（DomainException） |
| 401 | 未认证（Token 缺失/过期） |
| 403 | 无权限 |
| 500 | 系统异常 |
