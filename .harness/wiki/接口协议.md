# 接口协议

> 🔧 模板说明：「通用约定」按项目实际协议改写；接口分组与条目仅为示例，替换为真实 API 清单（URN 定义见 rules/01 §4）。

## 通用约定

| 项目 | 约定 |
|------|------|
| Base URL | `/api/` |
| Content-Type | `application/json` |
| 认证 | Header `Authorization: Bearer <token>` |
| 响应格式 | `{"code": 200, "msg": "success", "data": {...}}` |
| 错误响应 | `{"code": <errorCode>, "msg": "<message>"}` |
| HTTP Method | {按项目约定} |
